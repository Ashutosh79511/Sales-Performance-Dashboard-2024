## Sales Performance Dashboard 2024

A sales analytics project built in Google Sheets simulating real-world business reporting.

## What's inside
- Raw data of 300 sales orders
- Data cleaning and transformation
- Business analysis using SUMIF, COUNTIF, AVERAGEIF, INDEX MATCH
- Pivot Tables for regional, category and salesperson insights
- Interactive Dashboard with charts and KPI metrics

## Tools used
- Google Sheets
- Pivot Tables
- Excel formulas
